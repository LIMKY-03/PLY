# 주행 시뮬레이션 패널

실제 Pleos 차량이나 에뮬레이터 없이, PC 한 대에서 **경로선 → 경로 표지판 → 미니게임** 흐름을 시연하기 위한 차량 목업 확장이다.

차량 목업(`/play/vehicle`)에 "주행 시뮬레이션 · Pleos 내비 대체" 패널을 붙인다. 목업 차량이 Pleos 내비 보고 형식(`navigation.report`)으로 현재 위치와 목적지 좌표를 1초마다 보내고(`positionSource=SIMULATED`), 서버가 OSRM으로 만든 경로선을 따라 이동한다.

## 기능

- 경로 프리셋 3개(서울시청→서울역, 광화문→강남역, 여의도→서울역)와 좌표 직접 입력
- 표시 속도(30·50·80 km/h)와 시연 배속(1·3·10배). 배속은 이동 거리에만 적용되고 폰에 보내는 속도는 표시 속도 그대로다.
- 주행 중 목적지 변경: `routeRevision`을 올려 서버의 경로 재탐색과 표지판 재배치를 확인한다.
- 일시 정지, 안내 종료(기어 P)
- 상태 줄에 남은 거리, 다음 표지판까지 거리, 게임 가능한 표지판 수를 표시한다.

## 실행

```sh
cd server
ZRIDE_PUBLIC_ORIGIN=http://127.0.0.1:8000 npm start
```

1. `http://127.0.0.1:8000/play/demo`를 연다(왼쪽 차량 목업, 오른쪽 폰 화면).
2. 차량 목업에서 차량 연결 · 파티 생성 → 폰에서 QR 합류
3. 주행 시뮬레이션 패널에서 경로를 고르고 **안내 시작**
4. 폰 여행 지도에 경로선과 표지판이 나타나고, 차량이 표지판 500m 안에 들어오면 해당 게임을 열 수 있다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `drive-sim.js` | 패널 화면과 주행 로직. 서버가 `/play/drive-sim/drive-sim.js`로 제공한다. |
| `../vehicle.js` | `window.PLY_VEHICLE_MOCK`으로 차량 연결(방 상태, 메시지 전송, 로그)을 연다. `vehicle.report`에 `window.PLY_DRIVE_SIM`이 주는 주행 속도를 붙인다. |
| `../vehicle.html` | `drive-sim.js`를 불러온다. |

`vehicle.html`에서 스크립트 한 줄을 지우면 패널 없이 원래 차량 목업으로 돌아간다.
